# Sentinel Junction - IDS and IPS Lab

A static, browser-only beginner lab covering IDS and IPS placement, detection logic, alert triage, false positives, safe rule tuning and incident hand-off.

## Run locally

Open `index.html` directly in a browser. No installation, account, server or internet connection is required.

## Publish with GitHub Pages

Upload these three required files together without renaming them:

- `index.html`
- `styles.css`
- `app.js`

You may also publish `STUDENT-CLICK-BY-CLICK-GUIDE.txt`. Keep `INSTRUCTOR-ANSWER-KEY.txt` private if students should not see the solutions.

## Lab facts

- Suggested duration: 90-120 minutes
- 32 tracked activities
- 16 guided alert investigations
- 5 safe rule-tuning reviews
- Browser-saved progress
- Downloadable PNG certificate
- Responsive and GitHub Pages compatible
- No external requests or real traffic
